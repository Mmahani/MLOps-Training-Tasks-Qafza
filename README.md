# Qafza MLOps Training

## About the Training

This repository documents my learning journey through the **Qafza MLOps Training Program**. The training focuses on building reliable, scalable, and production-ready machine-learning systems.

The roadmap starts with machine-learning foundations and gradually progresses to APIs, containers, data pipelines, monitoring, automation, and infrastructure.

## Training Roadmap

| Week | Focus Area | Main Tools |
|---|---|---|
| 1 | Leakage-proof ML Pipeline | Python, Scikit-learn |
| 2 | Deep Learning Pipeline | PyTorch, Hugging Face |
| 3 | Production APIs | FastAPI, Pydantic |
| 4 | Containerization | Docker |
| 5 | Data Pipelines | Python ETL, Databases |
| 6 | Data Versioning | DVC |
| 7 | Experiment Tracking | MLflow |
| 8 | Distributed Training | Ray Core, Ray Train |
| 9 | Feature Store | Feast, Ray |
| 10 | Monitoring | Prometheus, Grafana |
| 11 | Continuous Retraining | Ray Serve, GitHub Actions |
| 12 | Infrastructure as Code | Terraform |
| Final | End-to-End ML System | Complete MLOps Stack |

## Repository Purpose

The repository is used to organize practical learning, experiments, notes, and implementations developed during the training program. Each stage is designed to build on the previous stage and improve understanding of the machine-learning production lifecycle.

## Goal

The main goal of this training is to develop the skills required to design, train, deploy, monitor, and maintain reliable machine-learning systems in production.
